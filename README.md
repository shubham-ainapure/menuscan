# MenuScan
MenuScan is a QR code-based menu management system designed for restaurant owners. 
It allows customers to scan a QR code to view the restaurant's menu online. 
Restaurant owners can easily manage their menus, categories, and dishes 
through a user-friendly interface.

## Features

- **User Authentication:** Secure login and registration for restaurant owners.
- **Menu Management:** Add, update, and delete categories and dishes.
- **QR Code Generation:** Automatically generate QR codes for each menu.
- **Responsive Design:** Optimized for both desktop and mobile views.
- **Real-Time Updates:** Instant updates to menu items and categories.
- **Image Uploads:** Upload images for dishes.
- **Customizable Menus:** Categorize dishes by meal type (e.g., breakfast, lunch, dinner).
- **Customer-Friendly:** Easy for customers to scan and view menus without needing an account.

## Usage

1. **Register and Login:**
   - Restaurant owners can register for an account.
   - Use the login page to access the menu management system.

2. **Manage Categories and Dishes:**
   - Add new categories for different meal types.
   - Add, update, and delete dishes within categories.
   - Upload images for each dish.

3. **Generate QR Codes:**
   - Generate and print QR codes for the restaurant's menu.
   - Display the QR codes for customers to scan.

4. **View Menu:**
   - Customers scan the QR code and view the menu on their devices.
